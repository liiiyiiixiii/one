# ONE · 今日清单

一个简洁的中文待办清单。用原生 HTML、CSS 和 JavaScript 编写，不需要安装依赖、注册账号或配置数据库。

## 开始使用

下载仓库后，双击 `index.html` 即可在现代浏览器中打开。

也可以通过本地服务器运行（需要 Python 3）：

```bash
git clone https://github.com/liiiyiiixiii/one.git
cd one
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。建议日常使用固定的浏览器与地址，保证读到同一份数据。

## 功能

- 添加待办事项，支持回车提交，最多 200 个字符。
- 勾选完成，或取消完成。
- 按全部、待完成、已完成筛选。
- 删除单条任务，或清除所有已完成任务。
- 显示剩余任务数和完成进度。
- 使用 localStorage 保存，并同步同源的浏览器标签页。
- 适配手机和电脑，支持键盘操作。

## 数据说明

数据仅保存在当前浏览器，不上传服务器、不跨设备同步。清理浏览器数据会删除任务；无痕模式、存储限制或直接打开本地文件可能影响保存。更换端口、浏览器或从本地文件改为服务器地址会使用不同的存储空间。保存失败时页面会提示；已有数据损坏时暂停写入，避免覆盖。

## 项目结构

```text
index.html            页面结构
style.css             页面样式和手机适配
app.js                页面交互与本地保存
tasks.js              任务处理逻辑
tests/tasks.test.cjs   功能测试
```

## 开发检查

安装 Node.js 18 或更新版本，无需 `npm install`：

```bash
npm run check
npm test
```

本项目没有构建步骤。修改文件后，刷新浏览器即可查看结果。
